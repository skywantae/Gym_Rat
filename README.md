# GymRat - 과학적 체성분 감량 및 식단 운동 관리 웹앱

사용자의 신체 스펙(키, 체중, 골격근량, 체지방률)과 목표를 기반으로 의학 및 스포츠 영양학적 알고리즘을 통해 안전한 주간 감량 페이스와 맞춤 식습관을 설계하는 크로스 플랫폼 반응형 웹 애플리케이션입니다.

- **안정화 배포 URL (GitHub Pages)**: https://skywantae.github.io/Gym_Rat/
- **현재 안정화 릴리스 버전**: v1.2.0-stable

---

## UI 레이아웃 불변 원칙 (Strict Layout Policy)

사용자의 명시적 지시에 따라 향후 새로운 기능이 추가되더라도 아래의 표준 화면 레이아웃은 **특별한 명령이 없는 한 엄격히 보존**됩니다.

1. **상단 헤더 (Top Header)**
   - 좌측: 브랜드 로고 (`GymRat`), 로그인 계정 표시, 로그아웃 버튼
   - 우측: `목표 설정` 및 `오늘 체성분 입력` 주요 작업 버튼

2. **최상단 중앙 운동 자극 명언 바 (Top Center Motivation)**
   - 대시보드 바로 위 한가운데에 단 한 줄로 배치
   - 별도의 잡다한 태그나 뱃지, 새로고침 버튼 없이 깔끔한 단일 문장으로 노출
   - 45종의 유명 스포츠 스타/철학자 명언 및 격언이 로그인/새로고침 시 순환 표시 (터치/클릭 시 셔플)

3. **PC / 폴더블 와이드 화면 2열 그리드 (Desktop / Foldable Bento Grid)**
   - **좌측 50% 열**: `몸무게 정보` 카드 (현재 몸무게, 이번 주 목표까지, 어제 대비 3열 증감, 요약/보고서 탭)
   - **우측 50% 열**: `내 맞춤 평소 식습관 & 일평균 영양 기준` 카드 (식품군별 조합기 및 끼니별 칼로리/단백질 집계)

4. **모바일 화면 (Mobile Single Column)**
   - 모바일 기기(아이폰, 갤럭시 전 시리즈)에서는 헤더 -> 최상단 중앙 명언 -> 몸무게 정보 카드 -> 식습관 카드가 위에서 아래로 직관적으로 연결되는 단일 열 배치

## 핵심 기능

1. **앳플리(Atflee) 스타일 몸무게 정보 및 주간 안전 감량 목표**
   - 좌측 오렌지 박스: 현재 몸무게(kg) 직관적 표시 (클릭 시 오늘 체성분 입력 모달 오픈)
   - 우측 화이트 박스: 의학/스포츠 영양학 안전 감량 기준(주당 0.5~1kg 감량 페이스) 기반 이번 주 목표까지 잔여 감량치 표시 (클릭 시 주차별 이전 기록 및 이후 예상 몸무게 로드맵 표시)
   - **어제 대비 3열 수치**: 몸무게, 골격근량, 체지방량 증감 실시간 계산
   - 요약 테이블 및 의학/스포츠 영양학 주간 안전 감량 리포트 탭 지원

2. **카테고리 기반 식품 조합기 & 맞춤 식습관 설계**
   - 닭가슴살/육류, 탄수화물/곡류, 채소류, 과일류, 계란/유제품, 보충제/음료 카테고리별 직관적 수량 및 중량(g/ml) 조합
   - 사용자가 직접 끼니를 추가/삭제하고 끼니별 및 일평균 칼로리/단백질/탄수화물/지방 자동 정밀 산출

3. **신규 계정 온보딩 5단계 위저드 & 논문 기반 도달 일수 시뮬레이터**
   - 1단계: 신체 스펙 (나이, 성별, 키, 체중, 골격근량, 체지방률)
   - 2단계: 운동 목적(다이어트, 바디 리컴포지션, 근비대, 스트렝스) 및 주간 빈도/강도
   - 3단계: 근무 환경 및 활동량
   - 4단계: 평소 식습관 식품 조합
   - 5단계: 목표 체중 및 스포츠 영양학/의학 임상 논문(NCBI StatPearls, Purcell et al., 유럽비만학회 ECO 등) 기반 추천 도달 일수 시뮬레이션

4. **Firebase Cloud Firestore 클라우드 동기화 & 로컬 슬롯 보존**
   - 본인 지정 아이디와 PIN 번호를 통한 간편 계정 생성 및 로그인
   - 설문 완료 플래그(`onboardingCompleted`), 맞춤 식단, 체성분 기록이 페이지 새로고침(F5) 및 로그아웃/재로그인 후에도 100% 영구 보존
   - 오프라인/온라인 환경 자동 전환 및 양방향 안전 병합

5. **체중 · 골격근량 · 체지방 변화 인터랙티브 그래프**
   - 7일, 30일, 90일, 180일, 전체 기간별 필터링
   - 오버레이, 체중 단독, 골격근량 단독, 체지방률 단독 뷰 지원
