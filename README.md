사용자의 신체 스펙(**184cm / 104.4kg / 골격근량 42.8kg / 체지방률 28.6%**)에서 최종 목표(**체중 90.0kg 달성 / 골격근량 41.0kg 이상 방어 / 체지방률 19~20% 타깃**)를 달성하기 위해 설계된 모바일 최적화 웹 애플리케이션입니다.

- **배포 URL (GitHub Pages):** `https://skywantae.github.io/Gym_Rat/`

---

## ✨ 핵심 기능

1. **앳플리(Atflee) 스타일 몸무게 정보 & 주간 안전 감량 목표 대시보드**
   - 좌측 시그니처 오렌지 박스: **현재 몸무게(kg)** 직관적 표시 (클릭 시 즉시 오늘의 측정값 입력)
   - 우측 목표 박스: 최종 목표까지 남은 총 감량치(`-14.40kg`)의 심리적 부담을 줄이고, 의학 및 스포츠 영양학 알고리즘(ACSM / ISSN / Helms et al. 2014 / Alpert 2005)이 계산한 **이번 주 목표까지 남은 감량치(예: `-0.58kg` / 주간 권장 `-0.78kg`)**를 메인으로 표시
   - **지난 번 대비** 3열 비교(몸무게 · 골격근량 · 체지방량) 및 **[요약 | 보고서(주간 감량 과학)]** 탭 제공

2. **매일 체중 · 골격근량 · 체지방량(kg) & 체지방률(%) 상호 자동 계산 입력**
   - 체지방량(kg) 입력 시 체지방률(%) 자동 계산, 체지방률(%) 입력 시 체지방량(kg) 자동 계산

3. **맞춤형 목표 설정 (`🎯 목표 설정`)**
   - 목표 체중(`90.0kg`), 최소 방어 골격근량(`41.0kg`), 목표 체지방률(`19.5%`), 신장(`184cm`), 일일 목표 칼로리(`2,250kcal`) 및 목표 단백질(`160g`) 자유 변경

4. **고정 식단 루틴 원클릭 등록 & 저녁 초저탄수·고단백 가이드**
   - 아침 고정 루틴 (`480 kcal / 단백질 40g`: 계란 3알 + 사과 1개 + 쉐이크 1스쿱)
   - 점심 고정 루틴 (`1,200 kcal / 단백질 28g`: 구내식당 식사 + 카페라떼 174kcal)
   - 단백질 160g 방어 부스터 (`180 kcal / 단백질 38g`: WPI 쉐이크 1.5스쿱)
   - 저녁 권장 가이드 3종 (`550~590 kcal / 단백질 51~58g`: 부채살 / 목살 / 닭가슴살 250g + 쌈채소)

5. **일일 필수 영양제·수분 체크리스트 & 주 4회 운동 세트 로깅**
   - 크레아틴 모노하이드레이트 5g, 프로바이오틱스 복용 스위치, 수분 섭취 트래킹(목표 2.8L)
   - 대근육 기구 웨이트 50분 세션 세트 기록 및 천국의 계단(StairMaster) 7~10분 인터벌 완료 체크

6. **체중 & 골격근량 오버레이 반응형 그래프**
   - `체중 + 골격근 오버레이`, `체중`, `골격근량`, `체지방률` 탭 전환 및 기간별(`1주`, `1개월`, `3개월`, `6개월`, `전체`) 필터링 지원
